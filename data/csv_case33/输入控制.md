# CSV 配电网数据格式约定（v1）

本文档定义 `data/csv_case33/` 下 CSV 数据文件的格式规范，用于替代 OpenDSS `.dss` 文本模型作为程序数据输入。
所有示例以模型 `model_storage_bus18` 的实际数据为基准。

> **默认算例 `model_default`（新设计，骨架态）**：基于现有模型精简规整而成，作为全新默认算例。
> 资源配置：PV(5) + 储能(1) + 可调度负荷 EV/AC(3) + 基础固定负荷 IEEE33(32)；电容器已建表但全部 `enabled=false`
> 且 `circuit.capacitor_enabled=false`（只留结构、不投运）。线路为完整 IEEE33 拓扑；
> `model_shapes.csv` 已填 96 点曲线；负荷 `shape` 已绑定曲线（`LoadX_cur` / EV/AC `cur/lb/ub`），
> 储能 `shape` 已绑定 `BESS_Bus18_en`（能量比例），光伏 `shape` 已绑定 `PV_BusX_irr`（辐照度曲线）。

## 1. 目录结构

每个模型一个文件夹（前缀 `model_`），全量放置 7 张 CSV：

```
data/csv_case33/{model}/
├── model_circuit.csv      # 系统参数 + 资源接入开关（必填）
├── model_lines.csv        # 线路（必填）
├── model_loads.csv        # 全部负荷（必填）
├── model_pvs.csv          # 光伏（可选，无光伏可缺省）
├── model_storage.csv      # 储能（可选）
├── model_capacitors.csv   # 电容器（可选）
└── model_shapes.csv       # 时间曲线 LoadShape（可选）
```

- 必填表：`circuit`、`lines`、`loads`。
- 可选表缺省 = 该资源不存在。
- 文件编码 UTF-8；表头行必须存在；列顺序与本文档一致。
- 布尔列统一用 `true` / `false`（大小写不敏感）。
- 数值单位与 DSS 一致（kW / kvar / Ω / A / kV / Hz / MVA），解析时统一转 pu。

| name | slack_bus | base_kv | phases | frequency | base_mva | pv_enabled | storage_enabled | ev_enabled | flexible_enabled | capacitor_enabled |

**资源接入规则（类别级 × 元件级叠加生效）**：
- `model_circuit.csv` 的 `*_enabled` 控制整类资源是否接入（对应 DSS `Master.dss` 中 `Redirect` 行是否注释）；
- 各资源表的 `enabled` 列控制单个元件是否投运；
- 二者均为 `true` 时该元件才算接入；任一为 `false` 即不接入。

## 4. model_loads.csv

所有负荷（基础固定负荷 / EV / 空调 / 额外固定负荷）合并于一张表，用 `type` 区分。

| 字段 | 类型 | 必填 | 说明 | 示例 |
|---|---|---|---|---|
| name | str | 是 | 负荷名 | EV_Bus19 |
| bus | str | 是 | 挂接母线 | bus19 |
| kv | float | 是 | 额定电压 (kV) | 12.66 |
| kw | float | 是 | **满载**有功 (kW) | 400 |
| kvar | float | 是 | **满载**无功 (kvar) | 100 |
| type | str | 是 | 类型：`fixed`/`ev`/`ac`/`fixed_extra` | ev |
| shape | str | 否 | 绑定的曲线名（当前挂载比例）；留空=当前=满载 | EV_Bus19_cur |
| npts | int | 否 | 曲线点数（仅 shape 非空时生效） | 1 |
| interval | float | 否 | 曲线步长 (h)（仅 shape 非空时生效） | 1 |
| mult_lb | float/str | 否 | mult 可调下限（相对满载），默认 0；**常数**或 **shapes 曲线名**（时变） | 0.3 |
| mult_ub | float/str | 否 | mult 可调上限（相对满载），默认 1；**常数**或 **shapes 曲线名**（时变） | 0.8 |
| enabled | bool | 是 | 是否投运 | true |

- `type=ev` / `type=ac` → 可调度负荷（dispatchable）；`fixed` / `fixed_extra` → 固定负荷。
- `kw`/`kvar` 一律填**满载容量**；当前实际挂载比例由绑定的 `shape` 曲线 `mult[0]` 给出。
- `mult_lb`/`mult_ub` 两种写法：
  - **常数**（数字）→ 各时间断面固定不变；
  - **shapes 曲线名**（字符串）→ 绑定 model_shapes.csv 中该曲线的时变 mult 序列作为各断面可调下限/上限（单断面取 `mult[0]`）；
- 绑定时变曲线后按显式配置处理，不再查 `LOAD_MULT_LIMITS` 配置表。
- `mult_lb` 高于当前挂载比例（`base_ratio`）时，加载层（load_network）统一收紧为当前挂载值并令 `z_lb=1`（该时段不允许继续削减），保证可调区间有效；此处理在 OPF 模型之外。
- `mult_ub` 低于当前挂载比例（`base_ratio`）时，加载层（load_network）统一放松为当前挂载值（当前时段负荷高于上报 ub 均值时，ub 放松至当前负荷），保证 `cur ≤ ub`、`z_ub ≥ 1`。
- `mult_lb`/`mult_ub` 替代原 Python 侧 `LOAD_MULT_LIMITS` 配置表。

示例（model_storage_bus18，共 38 行负荷，此处节选）：

| name | bus | kv | kw | kvar | type | shape | npts | interval | mult_lb | mult_ub | enabled |
|---|---|---|---|---|---|---|---|---|---|---|---|
| Load1 | bus2 | 12.66 | 100 | 60 | fixed |  |  |  |  |  | true |
| Load32 | bus33 | 12.66 | 60 | 40 | fixed |  |  |  |  |  | true |
| EV_Bus19 | bus19 | 12.66 | 400 | 100 | ev | EV_Bus19_cur | 1 | 1 | 0.3 | 0.8 | true |
| EV_Bus7 | bus7 | 12.66 | 600 | 150 | ev | EV_Bus7_cur | 1 | 1 | 0.1 | 0.8 | true |
| AC_Bus2 | bus2 | 12.66 | 200 | 100 | ac | AC_Bus2_cur | 1 | 1 | 0.1 | 0.8 | true |
| Fixed_Bus8 | bus8 | 12.66 | 200 | 66 | fixed_extra |  |  |  |  |  | true |
| Fixed_Bus22 | bus22 | 12.66 | 300 | 99 | fixed_extra |  |  |  |  |  | true |
| Fixed_Bus33 | bus33 | 12.66 | 100 | 33 | fixed_extra |  |  |  |  |  | true |

## 6. model_storage.csv

| 字段 | 类型 | 必填 | 说明 | 示例 |
|---|---|---|---|---|
| name | str | 是 | 储能名 | BESS_Bus18 |
| bus | str | 是 | 母线 | bus18 |
| kw | float | 是 | 额定功率 (kW) | 2500 |
| kwh | float | 是 | 额定能量 (kWh) | 5000 |
| state_of_charge | float | 是 | 初始 SOC (0-1) | 0.5 |
| pct_charge | float | 是 | 充电功率比例 (%) | 100 |
| pct_discharge | float | 是 | 放电功率比例 (%) | 100 |
| charge_eff | float | 是 | 充电效率 | 0.95 |
| discharge_eff | float | 是 | 放电效率 | 0.95 |
| pf | float | 否 | 储能功率因数（决定无功容量 q_max=kw×tan(acos(pf))），默认 0.95 | 0.95 |
| shape | str | 否 | 可用能量比例曲线名（**能量形状**，见下）；留空=1.0（全天满能量窗） | BESS_Bus18_en |
| npts | int | 否 | 曲线点数（仅 shape 非空时生效） | 1 |
| interval | float | 否 | 曲线步长 (h)（仅 shape 非空时生效） | 1 |
| energy_lb_ratio | float | 否 | 能量运行下限比例（相对额定 kWh），默认 0.1 | 0.1 |
| energy_ub_ratio | float | 否 | 能量运行上限比例（相对额定 kWh），默认 1.0 | 0.9 |
| enabled | bool | 是 | 是否投运 | true |

- **`shape` 是「能量」形状，不是「功率」形状**：绑定时，`mult[0]` 作为 `energy_ratio`，只缩放**能量窗口**（时间断面 t 时取 `mult[t]`）：

  ```
  energy_ub_cur = energy_ub_pu × ratio
  energy_lb_cur = energy_lb_pu × ratio
  ```

  其中 `energy_ub_pu / energy_lb_pu = energy_ub_ratio / energy_lb_ratio × 额定kWh / base_mva`。OPF 中能量状态 `se ∈ [energy_lb_cur, energy_ub_cur]`。
- **充放电功率与 `shape` 无关**：`charge_ub / discharge_ub = kw × pct_charge/pct_discharge`，由 `kw` 与 `pct_charge`/`pct_discharge` 决定，任何时刻都不随 `shape` 变化。
- **`state_of_charge` 只决定初始能量，不参与窗口本身**：`energy_init_cur = state_of_charge × energy_ub_cur`（单断面取窗口上限、SOC=1 时）。`shape` 缩放窗口 ⇒ 间接限制了该时段最大充/放电量（15 分钟约束 `se ± 0.25·p ≦/≧ 窗口边界`），但不直接限功率。
- **留空 `shape` 的后果**：`energy_ratio ≡ 1.0`，全天按满额定能量窗 `[energy_lb_ratio, energy_ub_ratio] × 额定kWh` 求解；若实际意图是按曲线缩放（如训练/场景同源的 `BESS_Bus18_en` 曲线），**必须**把曲线名填入 `shape` 列，否则 OPF 与特征/KNN 侧口径不一致（可能出现夜间储能满功率放电、根节点注入为负等失真）。
- `energy_lb_ratio`/`energy_ub_ratio` 替代原 Python 侧 `STORAGE_ENERGY_LIMITS` 配置表。

示例：

| name | bus | kw | kwh | state_of_charge | pct_charge | pct_discharge | charge_eff | discharge_eff | shape | npts | interval | energy_lb_ratio | energy_ub_ratio | enabled |
|---|---|---|---|---|---|---|---|---|---|---|---|---|---|---|
| BESS_Bus18 | bus18 | 2500 | 5000 | 0.5 | 100 | 100 | 0.95 | 0.95 | BESS_Bus18_en | 1 | 1 | 0.1 | 0.9 | true |

## 8. model_shapes.csv

时间曲线表，每行为一条曲线，第一列为曲线名，后续各列为时间戳（`时:分`）对应的数值。表头行为时间戳序列，从 `0:00` 到 `23:45`，共 96 个 15 分钟间隔点。

| 列 | 类型 | 必填 | 说明 | 示例 |
|---|---|---|---|---|
| name | str | 是 | 曲线名（被组件 `shape` 列引用） | EV_Bus19_cur |
| 时间戳列 | float | 是 | 各时间点的数值，列名格式为 `时:分`（0:00 ~ 23:45） | 0.5 |

- 表头行：`name,0:00,0:15,...,23:45`（共 97 列）。
- 数据行：第一列为曲线名，后续各列为对应时间点的数值。
- 解析时按列顺序读取，忽略列名含义（时间戳仅作标识）。
- 单断面程序取 `cells[1]`（即 `0:00` 时刻的值）作为当前断面值。
- `interval` 为点间步长 (h)，由引用组件定义（15min 对应 0.25h，96 点为全天曲线）。

| EV_Bus7_cur | 1.0 | 1.0 | 1.0 | 1.0 | ... | 0.1245 |
| AC_Bus2_cur | 0.087 | 0.087 | 0.087 | 0.087 | ... | 0.134 |
| PV_Bus6_irr | 0 | 0 | 0 | 0 | ... | 0 |
| PV_Bus14_irr | 0 | 0 | 0 | 0 | ... | 0 |
| PV_Bus19_irr | 0 | 0 | 0 | 0 | ... | 0 |

## 9. 解析语义与校验规则

1. 必填表缺失 → 报错；可选表缺失 → 视为无该类资源。
2. `shape` 列填写的曲线名必须在 `model_shapes.csv` 中定义；未绑定 `shape` 的组件忽略 `npts`/`interval`。
3. 表头行时间戳数目即为曲线点数（96 点 = 全天 15min 间隔），组件表 `npts` 若不一致时以实际 CSV 列数为准。
4. 资源接入 = `circuit.*_enabled == true` 且 元件 `enabled == true`。
5. `type=ev/ac` → 可调度负荷；`type=fixed/fixed_extra` → 固定负荷（不参与可调范围计算）。
6. 单断面程序取 `cells[1]`（首个时间点 `0:00` 的值）：负荷当前挂载比例、PV 当前辐照度、储能当前能量比例。
7. 拓扑由 slack 出发，基于 `enabled=true 且 is_switch=false` 的线路 BFS 构建。
8. 数据单位均为工程单位，解析后在 `Network.finalize()` 中转 pu（基准由 `model_circuit.csv` 的 `base_mva`/`base_kv` 决定）。
